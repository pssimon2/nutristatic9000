Almost, but not quite, entirely unlike tea.

Matches patterns against a dictionary of words and phrases. Text is normalized to lowercase letters, numbers and spaces. More common results are returned first. All searching happens in your browser — there is no server.

Syntax

  • a-z, 0-9, space - literal match
  • [], (), {}, |, ., ?, *, + - same as regexp
  • "expr" - forbid word breaks without a space or hyphen
  • expr&expr - both expressions must match
  • !expr - match what expr does not
  • <aaagmnr>, <(gram)(ana)> - anagram of contents (note warnings)
  • _ (underscore) - alphanumeric, not space: [a-z0-9]
  • # (number sign) - digit: [0-9]
  • - (hyphen) - optional space: ( ?)
  • A - alphabetic: [a-z]
  • C - consonant (including y)
  • V - vowel ([aeiou], not y)

9000 extensions

Each of these is a live example — click to run it. They combine with everything above. What each one does »

  • Counts and values: {sum=100:A*}, {scrabble>25:A{5}}, {count(e)=2:A{5}}, {count(vowel)<=1:A{5}}, {distinct:A{6}}, {maxrep=1:A{5}}, {all(aeiou):A*}, {letters=11:A*}, {words=3:A*}
  • Banks and edits: <<washington>>, {sub:cryptography}, {del1:beast}, {add1:cargo}, {subst1:cargo}, {edit<=2:cargo}
  • Ciphers and encodings: {caesar:kdhv}, {rot13:cvmmn}, {atbash:gsv}, {t9:2665}, {enum:4,3,5}, {morse:.....--.-..}, {elements:A{6}}
  • Letter shapes and keys: {roman:A{5}}, {rot180:A{5}}, {mirror:A{5}}, {sevenseg:A{6}}, {holes=0:A{6}}, {row1:A{6}}, {ascending:A{5}}, {descending:A{4}}
  • Questions for the corpus: {compound 2:A{9}}, {palindrome:A{5}}, {reversible:A{6}}, {list:greek}, {list:red,green,blue}
  • Several answers at once: separate patterns with ; to run them together and read the extraction across them — {at 1:<aaagmnr>} ; {at 2:solar s_stem} ; {at 1:A{5}&.*zz.*}
  • What you get back: {at 3:A{7}}, {at 1.1,-1.1:A* A*}, {rank 200-2000:A{5}}, !.*ee.*&A{5}
  • Also: the matched shift is shown beside {caesar:…} results, the split beside {compound …} results, and repeats of one phrase are folded together with a link under the results to restore them.
