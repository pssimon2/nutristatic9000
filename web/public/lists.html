List catalogue

Every name here works as {list:name} in a query — so {list:romandeities}&A{4} is a four-letter Roman deity. Lists compose with everything else: intersect them, put them inside {del1:…}, or hide one inside a phrase with .*{list:…}.*.

The small built-in lists ship with the app. The rest are harvested from Wikipedia and fetched the first time a query asks for one, so they need a network connection — the built-ins keep working offline.
